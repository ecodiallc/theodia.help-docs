# Theodia Help Docs

Downloadable help bundles for [Theodia](https://theodia.app). English help is built into the app itself; every other supported locale is published here as a `.help.zip` bundle that the app can download and update between app releases. Open **Settings** → **Help** or **Manage Resources** → **Install from GitHub** → **Help docs** in the app.

Each bundle's `manifest.json` inside the zip lists its files with SHA-256 hashes; `index.json` in this repo lists every bundle's version (`<app version>-<content hash>`), SHA-256 and size. The app fetches `index.json` to decide what to update.
