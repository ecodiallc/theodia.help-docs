# Theodia.app Help Docs

This repository hosts downloadable help documentation bundles for [Theodia.app](https://theodia.app). The app discovers these bundles through `index.json` and downloads the bundle matching the user's UI language.

---

## Supported languages

| Locale | Native name | File | Size | Version |
| ------ | ----------- | ---- | ---- | ------- |
| `ar` | العربية | [`ar.help.zip`](ar.help.zip) | 110 KB | `0.1.5-e6952da` |

---

## Bundle format

Each language is shipped as a zip file named `<locale>.help.zip` containing:

- `manifest.json` — bundle metadata (`locale`, `version`, `generatedAt`, and a per-file manifest of sha256 + bytes)
- `help/<locale>/<slug>.md` — one Markdown file per help guide

The runtime first looks for an installed bundle under the app's document directory (`help/<locale>/`), then falls back to the English bundle bundled with the app.

---

## Index format

`index.json` follows the app's `RepoPackageIndex` schema and is consumed by `mergeGitHubResults()` in `src/utils/resourceManager.ts`:

```json
{
  "id": "help-ar",
  "type": "helpDocs",
  "path": "ar.help.zip",
  "name": "العربية",
  "locale": "ar",
  "version": "0.1.5-e6952da",
  "sha256": "241b5ace65bec23575f420ed27a27e38ce7c0f213a36631ad7607108c3086ae3",
  "bytes": 110489
}
```

---

## Publishing

Bundles are generated by `npm run copy:help` in the main `theodia.app` repository and published here with `npm run upload:help`.
